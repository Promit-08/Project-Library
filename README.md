# Project Library: Academic Sanctuary

**Project Library** is a collaborative research platform designed for scholars and undergraduate innovators to share, explore, and peer-review academic work in a polished, distraction-free environment.

## 🌟 Overview

The platform serves as a digital sanctuary for knowledge, enabling users to maintain a personal archive of their works while discovering groundbreaking research from peers. With a focus on scholarly identity and high-quality interaction, Project Library bridges the gap between individual research and institutional collaboration.

## 🚀 Key Features

-   **Scholarly Identity:** Personalized profiles featuring verified scholar status, custom display names, and avatars.
-   **Collaborative Library:** Upload, categorize, and archive projects with detailed metadata including sector, field, and smart tagging.
-   **Research Tools:** Integrated AI-powered domain prediction and YouTube research search to deepen academic exploration.
-   **Peer Interaction:** Robust engagement system with multi-tier ratings, likes, and a threaded commenting system.
-   **Real-time Engagement:** Instant notifications for peer feedback, ratings, and collaborative interactions.
-   **High-Fidelity UI:** A premium aesthetic with fluid animations, adaptive light/dark modes, and a mobile-first responsive design.
-   **Secure Infrastructure:** Role-based access control and data security powered by Supabase Auth and RLS (Row Level Security).

## 🛠️ Technology Stack

-   **Frontend:** React 19, Vite, Tailwind CSS
-   **Animation:** Framer Motion (Motion), GSAP
-   **Backend:** Supabase (PostgreSQL, Realtime, Edge Functions, Storage)
-   **AI Integration:** TensorFlow.js, Google Gemini API
-   **Visuals:** Recharts (Data Visualization), Lucide Icons, Radix UI Primitives
